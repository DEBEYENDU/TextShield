Title: Technical Support Scam (Remote Access)
Category: scams
Subcategory: technical_support
Summary: Scammers gain remote access to victim's computer under false pretenses of fixing technical issues.
Description: Remote access tech support scams involve convincing victims their computer has serious problems (viruses, system errors, performance issues). The scammer requests remote access software (TeamViewer, AnyDesk, etc.) "to diagnose and fix the problem." Once accessed, they may steal files, install malware, view passwords, or charge exorbitant fees for unnecessary "repairs."
Typical Scenario: "Your computer has critical errors. I need remote access to fix it" or "We detected malware - allow remote scanning"
Intent: Financial theft and malware installation through remote access
Behavior: Victim grants remote access; scammer steals data or charges for fake repairs
Manipulation Techniques: Fear (computer problems), Authority (tech support), Trust Building (technical expertise), Urgency (immediate fix needed)
Common Indicators: Unsolicited tech contact; requests to install remote access software; claims of multiple serious errors; payment demanded for fake fixes
Legitimate Alternatives: Genuine remote tech support you've contacted; manufacturer support; antivirus software; local repair shops
False Positives: Legitimate remote support sessions you've initiated
False Negatives: Victims who grant access thinking it's their own tech support company
Real-world Examples: "Computer repair scam," "Virus removal extortion," "IT support impersonation"
