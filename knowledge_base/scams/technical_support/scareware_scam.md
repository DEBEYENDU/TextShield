Title: Tech Support Scareware
Category: scams
Subcategory: technical_support
Summary: Malware or fake software that displays false security warnings to extort money.
Description: Scareware tricks victims into believing their computer has viruses, registry errors, or security vulnerabilities. Fake scan results are displayed, prompting victims to purchase "full version" software to fix non-existent problems. The software may be useless, malware, or simply a money-extraction scheme.
Typical Scenario: Website visit triggers full-screen scan "WARNING: 107 viruses detected!" → prompts to "Remove all threats now" for $99.99
Intent: Financial extraction through fake security software
Behavior: Victim purchases fake software; may also install actual malware
Manipulation Techniques: Fear (viruses detected), Urgency (protect your computer), Authority (fake security scan)
Common Indicators: Full-screen scan won't close; long list of "threats"; prompts to buy software; pop-ups recurring; system performance unchanged after "treatment"
Legitimate Alternatives: Genuine antivirus software; OS built-in security; reputable security companies you've subscribed to; system restore
False Positives: Actual malware infections that coincidentally show similar warnings
False Negatives: Users who trust fake scans and miss real infections, or vice versa
Real-world Examples: "System Optimizer Pro" scams, "PC Repair Scamware," "Antivirus 2024" fake software
