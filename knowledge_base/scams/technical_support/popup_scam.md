Title: Technical Support Scam (Pop-up)
Category: scams
Subcategory: technical_support
Summary: Fraudulent pop-up warnings mimicking system alerts to extract money or install malware.
Description: Pop-up tech support scams display fake system warnings ( "Your computer is infected!", "Security alert!", "Windows Critical Error!") that cannot be closed normally. They instruct victims to call a phone number or click a link for "support." The pop-up may play audio or mimic system dialogs to appear legitimate.
Typical Scenario: Website visit triggers pop-up "Your computer is at risk! Call 1-800 number immediately!" or "Security alert - viruses detected!"
Intent: Financial extraction and malware installation through fake support
Behavior: Victim calls number or clicks link; may pay for fake support or download malware
Manipulation Techniques: Fear (system infection), Urgency (immediate action), Authority (fake system alerts)
Common Indicators: Pop-up that won't close; claims of viruses/security risks; phone number displayed; poor grammar; mimics official OS dialogs
Legitimate Alternatives: Genuine system notifications from OS/security software; task manager to close browser; legitimate security company pop-ups you've subscribed to
False Positives: Actual malware infections that happen to trigger legitimate security warnings
False Negatives: Users who miss real security warnings among fake pop-ups
Real-world Examples: "Windows Security Alert" pop-ups, "McAfee subscription expired" warnings, "Apple Security Detection" scams
References: FTC Pop-up Scam Reports; Norton Cyber Safety Report; Microsoft Edge Security Features
