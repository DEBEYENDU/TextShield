Title: Password Reset Scam
Category: scams
Subcategory: technical_support
Summary: Fraudulent password reset requests aiming to capture credentials or install malware.
Description: Password reset scams involve fake password reset links, forms, or calls claiming the user's account needs verification. The fake reset page captures credentials, or the "reset" process installs malware. Victims are directed to fraudulent sites via email, SMS, or pop-up warnings.
Typical Scenario: "Your password has expired - reset now" via email or SMS with link to fake login page; pop-up "Your computer needs security update - click to reset password"
Intent: Credential theft and unauthorized account access
Behavior: Victim enters credentials on fake page; scammer gains account access
Manipulation Techniques: Urgency (account lockout), Authority (claimed service provider), Fear (lost data/access)
Common Indicators: Unsolicited password reset request; link to non-official domain; pop-up warning about account security; requests to disable antivirus
Legitimate Alternatives: Official password reset through service's website or app; email from known sender with verification link
False Positives: Legitimate password reset initiated by user
False Negatives: Users who don't check for official reset communications
Real-world Examples: "Bank password reset" phishing, "Email account verification" scams, "Software license renewal" pop-ups
References: APWG Password Phishing Reports; NIST Digital Identity Guidelines; FTC Phishing Data
