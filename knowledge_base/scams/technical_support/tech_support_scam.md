Title: Technical Support Scam
Category: scams
Subcategory: technical_support
Summary: Fraudulent communications claiming computer has viruses or issues, offering fake support services.
Description: Technical support scams involve unsolicited contact claiming the victim's computer is infected, has errors, or is performing poorly. The scammer offers "fixes" for a fee, often requesting remote access to the computer, installing actual malware, or extracting payment for unnecessary services.
Typical Scenario: "Your computer has been infected with 3 viruses. Call this number immediately" or "We detected malware on your device."
Intent: Financial gain and malware installation
Behavior: Victim pays for unnecessary services or grants remote access to scammer
Manipulation Techniques: Fear (computer infection), Authority (claimed tech support), Trust Building (known tech context)
Common Indicators: Unsolicited tech support contact; requests for remote access; demands for payment to fix imaginary issues; pressure to act immediately
Legitimate Alternatives: Genuine tech support from service providers; antivirus software detecting actual threats; user-initiated support requests
False Positives: Actual computer performance issues unrelated to malware
False Negatives: Victims who grant access thinking it's legitimate support
Real-world Examples: "Windows Support Scam," "Apple Security Alert" pop-ups
