Title: Travel Bookings and Itineraries
Category: legitimate
Subcategory: travel
Summary: Genuine flight, train, hotel and cab booking confirmations with PNR, check-in and cancellation details.
Description: Travel confirmations contain booking references, passenger names, schedules and links to the airline, railway or hotel site the user booked on. Changes arrive as updates to an existing PNR, never as demands for extra payment over SMS links, and refunds go to the original payment method.
Typical Scenario: "PNR 4829163750 confirmed" or "Hotel booking in Jaipur" or "Cab booked, driver arriving" or "Flight rescheduled"
Intent: Confirm bookings and update travellers
Behavior: Traveller checks in with the PNR; contacts official support for changes
Manipulation Techniques: None (booked travel workflow)
Common Indicators: Matches a booking the user made; PNR or booking ID present; operator name; no extra-fee links; refund to source account
Legitimate Alternatives: None - this is the legitimate communication itself
False Positives: Real itineraries flagged because they contain "confirm", "urgent rebooking" or payment references
False Negatives: Travellers missing rescheduling updates
Real-world Examples: "IndiGo booking confirmed", "IRCTC PNR status", "MakeMyTrip hotel voucher", "Uber cab details"
References: Airline CRS Standards; IRCTC Policies
