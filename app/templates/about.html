Project

TextShield is an academic engineering project that detects SPAM and HAM across SMS, text and email, and explains every verdict using a three-layer architecture:

  • ▶ ML classifier (TF-IDF → Linear SVM) is the primary decision maker.
  • ▶ RAG system retrieves relevant evidence from a local knowledge base via semantic search (ChromaDB + sentence-transformers).
  • ▶ LLM layer (Ollama / OpenAI-compatible, optional) writes the human-readable explanation; a deterministic template takes over when no LLM is configured.

The ML model never depends on the LLM or RAG: the application still returns SPAM/HAM, confidence and indicators when the advanced services are offline.

Scope & limitations

  • ⓘ All analyses are informational and based on static pattern analysis. TextShield is not legal, financial or security assurance.
  • ⓘ URL analysis is purely structural (no network requests); a clean URL is not a guarantee of safety.
  • ⓘ Accuracy depends on the training dataset. The bundled sample dataset is small; adding the UCI SMS Spam Collection greatly improves the model.
