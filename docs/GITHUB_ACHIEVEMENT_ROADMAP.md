### Achievements Requiring Manual GitHub UI Interaction

**MANUAL ACTION REQUIRED**

These cannot be safely automated via local git:

- Open/close issues
- Open/create pull requests
- Review PRs
- Star repositories
- Create GitHub Releases
- Enable repository Discussions / Topics / Labels
- Invite collaborators / set CODEOWNERS
- Create Projects, Milestones
- Grant repository permissions

**Beginner-friendly instructions:**
1. Go to https://github.com/DEBEYENDU/TextShield
2. For issues: Issues → New issue → Choose template or Bug Report
3. For PR: Create branch locally → push → GitHub UI "Compare & pull request"
4. For release: Releases → Draft new release → tag → publish
5. For labels: Settings → Labels → New label

### Achievements Not Realistically Automatable

- **Arctic Code Vault Contributor** – requires GitHub archival selection
- **Starstruck** – requires starring 100+ unrelated repos, personal choice
- **Public Sponsor** – requires monetary sponsorship
- **Global Achievements** – some depend on GitHub-wide events
